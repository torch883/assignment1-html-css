Coursework project for the "HTML & CSS Basics" course by **Mukashev Arman**
(Group SE-2530, AITU). Covers Tasks 1–4 of Assignment 1.

Every task page includes a navigation bar linking to all four tasks,
so the site can be browsed from any page.

## Tasks

1. **Task 1 — Personal page** (`task1/`)
   Semantic HTML with headings, lists, a styled image, links, and a
   profile card. Demonstrates element, class, and ID selectors, the
   CSS box model, and a hover effect on links.

2. **Task 2 — Layout with `<div>`** (`task2/`)
   A classic header / navbar / sidebar / content / footer layout
   built only with `<div>` elements and `float` positioning — no
   Flexbox or Grid.

3. **Task 3 — Tribute page** (`task3/exercise1/`)
   A tribute page for Elon Musk, founder of Tesla and SpaceX. Uses
   two Google Fonts (Open Sans and Playfair Display), a life
   timeline, a list of key inventions, a photo, and links to his
   X profile and Wikipedia page.

4. **Task 4 — Table and form** (`task4/`)
   A course grades table using `colspan` and alternating row colors,
   plus a feedback form with a text field, email field, select,
   radio buttons, a textarea, and a submit button.

## Running locally

Open `index.html` in a browser — it redirects straight to
`task1/index.html`, and the navbar on every page links to the rest
of the tasks.
